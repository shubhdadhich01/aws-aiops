# Day 04 — serverless_audit.py dependencies
#
# boto3 is the only hard requirement. Everything else the tool uses is standard
# library (argparse, csv, json, re, dataclasses) on purpose: an audit tool you
# can copy onto a bastion or into a Lambda layer and run with nothing installed
# is worth more than one with a beautiful dependency tree.
#
#   pip install -r requirements.txt
#
# The unit tests need nothing beyond this either — every check is a pure
# function over dictionaries, so tests/test_checks.py runs with no credentials,
# no account and no network.

boto3>=1.34.0
botocore>=1.34.0
